6. Por qué falló la generación

Se midió con una ráfaga de 8 llamadas seguidas al modelo: las 6 primeras responden 200 y la séptima devuelve 429 You exceeded your current quota. Un lote del pipeline hace más llamadas por minuto (una por mensaje para el análisis, más la generación), así que parte del trabajo supera el límite de la capa gratuita. Además gemini-3.8-flash respondió 503 (alta demanda) y gemini-flash-latest tuvo timeouts. Subir LLM_MAX_RETRIES a 8 no fue suficiente.

No es un fallo del panel ni del backend: es un límite de cuota de la clave. Pero hasta repetirlo con cuota suficiente, la generación con IA no puede darse por validada.

7. Hallazgos para el equipo

  • Modelos Gemini retirados: el valor por defecto del código (gemini-2.5-flash en ai_modules/multiprovider_agent.py) y el de .env.example (gemini-1.5-flash) ya no están disponibles para claves nuevas. Con una clave nueva hay que fijar GEMINI_MODEL. Conviene actualizar ambos.
  • El ejemplo del panel no se puede reenviar: el botón «Enviar datos de ejemplo» usa un request_id fijo; tras el primer envío el backend lo trata como duplicado y devuelve el mismo run (incluso si falló). Para repetir pruebas hay que cambiar el request_id.
  • Revisión del PR #28: se encontró y corrigió un 503 al arrancar la API con la base vacía (PR #30). Quedan 8 mejoras menores sin tratar; el detalle está en el comentario del #28.

8. Cómo repetirlo con el bucket del equipo

  1. En .env: GEMINI_API_KEY (con cuota suficiente), GEMINI_MODEL y las variables OCI_* del equipo (las gestiona Michael). Nunca subir el .env al repositorio.
  2. Levantar los tres procesos desde la raíz, con COMMUNITYLAB_WEBHOOK_SECRET definido:
    uv run --frozen uvicorn api.main:app --host 127.0.0.1 --port 8000
    uv run --frozen python -m orchestration.worker
    uv run --frozen streamlit run ui/app.py --server.address 127.0.0.1
  3. Subir un lote desde Carga (con request_id nuevo), esperar el estado completado, revisar Resultados y Edición, aprobar y guardar en OCI.
  4. Si la clave es gratuita, esperar al menos un minuto entre lotes.
  5. Comprobar que el texto del editor no sea la plantilla de respaldo.
